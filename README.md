# 🍥 Academia Ninja - Web App Interactiva

> Proyecto de desarrollo web Frontend con temática de Naruto | JavaScript + LocalStorage

Aplicación web interactiva que simula un "Tablero de Misiones" de una academia ninja. Permite a los usuarios registrar, visualizar y gestionar servicios estudiantiles utilizando persistencia de datos en el navegador.

## 🚀 Características Principales
* **CRUD de Misiones:** Registro y lectura de datos en tiempo real.
* **Persistencia de Datos:** Uso de `localStorage` para guardar las misiones aunque se cierre el navegador.
* **Validaciones Dinámicas:** Comprobación de campos y reglas de negocio (precios, elementos).
* **UI/UX Temática:** Diseño inmersivo estilo anime con animaciones CSS avanzadas y efectos visuales.
* **Algoritmos:** Cálculo automático de estadísticas (Misión más cara, promedio de precios, etc.).

## 🛠️ Tecnologías
* HTML5 Semántico
* CSS3 (Animaciones, Flexbox, Grid, Variables)
* JavaScript (ES6+, DOM Manipulation)
